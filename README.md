# 小学生野球チーム記録 Webアプリ

## できること
- 選手登録
- 試合登録（大会名・対戦相手・球場）
- スタメン／打順／守備位置設定
- イニング別スコア
- 打席結果入力
- 打点・盗塁・得点入力
- 代打／選手交代
- 過去試合の修正
- チーム成績自動集計
- 大会別・期間別・打順別・守備位置別フィルター
- 選手ごとの全体／打順別／試合別成績
- ランキング
- JSONバックアップ／復元
- ホーム画面追加対応（PWA）

## 使い方
このフォルダ一式を静的Webホスティングに置いてください。
例：GitHub Pages / Netlify / Cloudflare Pages / Xserver の公開フォルダ。

公開後、iPhoneではSafariでURLを開き、
共有 →「ホーム画面に追加」
でアプリのように使えます。

## データ保存
記録は端末のブラウザ内（localStorage）に保存されます。
設定画面から定期的に「バックアップを書き出す」を行ってください。

## 注意
同じURLでも、別のスマホ・別のブラウザではデータは自動共有されません。
複数人で共有して使う場合は、次の段階でオンラインDB（Supabase / Firebase等）を追加してください。
