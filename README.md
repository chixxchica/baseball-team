# 小学生野球チーム記録 Ver.1.1.5

## 今回の更新
- 打席開始時の走者（1塁・2塁・3塁）を任意記録
- 得点圏打率を自動集計（2塁または3塁に走者がいる打席）
- 打球方向（左・左中・中・右中・右）を任意記録
- 打席メモを任意記録
- 長打率（SLG）・OPSを自動集計
- 同日複数試合を「第1試合〜第4試合」で区別
- 成績の開始日・終了日の入力欄をスマホ向けに調整
- Ver.1.1.4までの試合削除、打席編集、試合切替、投手成績、CSV取込等を維持

## GitHub Pages 更新
ZIPを解凍し、ルートにある6ファイルをすべて既存リポジトリへ上書きアップロードしてください。

- index.html
- sw.js
- manifest.webmanifest
- README.md
- icon-192.png
- icon-512.png

既存データは同じ localStorage キーを使用するため引き継がれます。更新前に設定画面からバックアップを書き出しておくと安心です。
